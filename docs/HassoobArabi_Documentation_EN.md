## 1. Project Overview

**Hassoob Arabi** (حاسوب عربي, *"Arabic Computer"*) is a complete programming language whose **keywords, identifiers, numerals, and error messages are all in Arabic**, and whose source files use the `.حع` extension. It is inspired by Wolfram Mathematica: beyond ordinary imperative programming, it treats **symbolic mathematics** as a first-class citizen — you can declare symbols, differentiate, integrate, take limits, expand Taylor series, solve equations, work with matrices, compute statistics, and draw plots, all using Arabic commands.

Key characteristics:

- **Arabic syntax** — control-flow keywords (`إذا`, `بينما`, `لكل`, `دالة`, …), built-in functions (`اطبع`, `اشتقق`, `متوسط`, …), and operators read naturally in Arabic.
- **Arabic-Indic numerals** — both `٠١٢٣` and `0123` are accepted in source, and **all output is printed with Arabic numerals** (٠–٩).
- **Symbolic + numeric engine** — symbolic algebra/calculus via SymPy, fast numeric/linear-algebra via NumPy, plotting via Matplotlib.
- **Friendly errors** — every error is a cute, fully-Arabic message in the canonical form `خطأ في السطر {line}، العمود {col}: …`, often with a *"did you mean…"* (`هل تقصد`) suggestion.
- **RTL IDE** — a right-to-left editor with syntax highlighting, instant run, and an interactive REPL.

## 2. Architecture & Compilation Pipeline

Hassoob Arabi is a **tree-walking interpreter** built on an ANTLR4 front end. A source file flows through the following stages:

```
  source.حع
      │
      ▼
┌─────────────┐   Lexer + Parser generated by ANTLR4 from HassoobArabi.g4
│  Front end  │   → produces a concrete parse tree
└─────────────┘
      │  parse tree
      ▼
┌─────────────┐   ast_builder.py walks the parse tree
│ AST builder │   → produces a clean Abstract Syntax Tree (ast_nodes.py)
└─────────────┘
      │  AST
      ▼
┌─────────────┐   semantic.py: undefined-variable checks, arity checks,
│  Semantic   │   break/continue/return placement, "did you mean" hints
└─────────────┘
      │  validated AST
      ▼
┌─────────────┐   optimizer.py: constant folding, algebraic simplification,
│  Optimizer  │   dead-branch elimination
└─────────────┘
      │  optimized AST
      ▼
┌─────────────┐   interpreter.py walks the AST; environment.py holds the
│ Interpreter │   scope chain; builtins.py provides the standard library
└─────────────┘
      │
      ▼
  console output (Arabic numerals) + Matplotlib plot windows
```

**Stage responsibilities**

| Stage | Module(s) | Responsibility |
|---|---|---|
| Lexing & parsing | `generated/` (from `HassoobArabi.g4`) | Tokenize Arabic source and build a parse tree per the grammar. |
| AST building | `src/ast_builder.py`, `src/ast_nodes.py` | Convert the parse tree into typed AST nodes. |
| Semantic analysis | `src/semantic.py` | Static checks: undefined names, wrong argument counts, misplaced `إرجع`/`اوقف`/`استمر`. |
| Optimization | `src/optimizer.py` | Constant folding, simplification, removing unreachable branches. |
| Interpretation | `src/interpreter.py`, `src/environment.py` | Execute the AST; manage the (Mathematica-style) scope chain. |
| Standard library | `src/builtins.py`, `src/runtime_ops.py`, `src/lang_utils.py` | Built-in functions, operator semantics, helpers. |
| Errors | `src/errors.py` | Friendly Arabic exception hierarchy + control-flow signals. |
| Tooling | `src/repl.py`, `ide/` | Interactive REPL and the RTL graphical IDE. |

## 4. Installation & Running

### Requirements
- Python 3.10+
- `antlr4-python3-runtime`, `sympy`, `numpy`, `matplotlib`, `scipy`, `prompt_toolkit`, `rich`, `pytest`
- `PySide6` *(optional)* — enables the true-RTL Qt editor; without it the IDE falls back to Tkinter.

### Setup
```bash
pip install -r requirements.txt

# Generate the parser from the grammar (needs Java + the antlr4 tool):
antlr4 -Dlanguage=Python3 -visitor -o generated HassoobArabi.g4
```

### Running
```bash
python main.py                     # interactive REPL
python main.py examples/مرحبا.حع    # run a source file
python main.py -c "اطبع(٣+٤)"       # run a single expression
python main.py --ide               # launch the graphical IDE
python -m ide                      # (equivalent) launch the IDE
```

### Tests
```bash
pytest tests/
# Each suite also runs standalone and builds ASTs directly,
# so tests pass even before the ANTLR parser is generated.
```

## 5. Language Reference

### 5.1 Numerals, comments, and statements
- **Numerals:** Arabic-Indic (`٠١٢٣٤٥٦٧٨٩`) and Western (`0-9`) digits are both valid. Floating point requires an ASCII dot: `٢.٥`.
- **Statements** end at a newline; an optional terminator `;` or the Arabic semicolon `؛` is allowed.
- **Comments:**
  - `# ...` — line comment
  - `ملاحظة ...` — Arabic line comment
  - `/* ... */` — block comment

### 5.2 Variables & assignment
```text
أ = ٧                 # assignment
أ += ٣                # augmented assignment: += -= *= /= %= ^= ++=
النص ++= "!"          # ++= appends to a string
```
The interpreter uses a **Mathematica-style scope chain**: functions introduce a new scope and resolve free names against enclosing scopes.

### 5.3 Data types
| Type | `نوع` returns | Example |
|---|---|---|
| Number | `عدد` | `٣`, `٢.٥`, `-٧` |
| Boolean | `منطقي` | `صحيح`, `خطأ` |
| String | `نص` | `"مرحبا"`, `'نص'` |
| Null | `فارغ` | `فارغ` |
| List | `قائمة` | `[١, ٢, ٣]` |
| Matrix / array | `مصفوفة` | `[[١,٢],[٣,٤]]` (via numeric ops) |
| Symbolic | `رمزي` | result of `رمز س` |
| Function | `دالة` | a `دالة` or lambda |

### 5.4 Operators
| Category | Operators |
|---|---|
| Arithmetic | `+`  `-`  `*`  `/`  `%` (mod)  `^` (power)  `÷` (integer division) |
| Matrix | `**` (matrix multiply) |
| String | `++` (concatenation — formats both sides) |
| Comparison | `==`  `!=`/`≠`  `<`  `<=`/`≤`  `>`  `>=`/`≥` (chainable: `٦٠ <= د < ٩٠`) |
| Logical | `و`/`&&` (and)  `أو`/`||` (or)  `ليس`/`!` (not) |
| Assignment | `=`  `+=`  `-=`  `*=`  `/=`  `%=`  `^=`  `++=` |
| Lambda arrow | `=>` |

**Symbolic constants:** `باي` / `π`, `هـ` (Euler's *e*), `لانهاية` (infinity).

### 5.5 Control flow
```text
# Conditional
إذا (أ > ب) {
    اطبع("أكبر")
} وإلا إذا (أ == ب) {
    اطبع("متساوٍ")
} وإلا {
    اطبع("أصغر")
}

# While loop
بينما (س < ١٠) { س += ١ }

# For-each over a sequence
لكل عنصر في [١, ٢, ٣] { اطبع(عنصر) }

# For-range (inclusive of both ends; optional بخطوة step)
لكل ع من ١ إلى ٥ { اطبع(ع) }
لكل ع من ١٠ إلى ١ بخطوة -٢ { اطبع(ع) }
```
`اوقف` = break, `استمر` = continue.

### 5.6 Functions & lambdas
```text
دالة مربع(س) {
    إرجع س * س
}

دالة عاملي(ن) {
    إذا (ن <= ١) { إرجع ١ }
    إرجع ن * عاملي(ن - ١)     # recursion
}

# Lambdas: single param without parentheses, or (a, b) => ...
مضاعف = س => س * ٢
جمع    = (أ, ب) => أ + ب
```

### 5.7 Strings & f-strings
```text
الاسم = "جعفر"
اطبع("مرحبًا يا " ++ الاسم)            # ++ concatenation
اطبع(f"الطول هو {طول(الاسم)} حروف")   # f-string interpolation
```
Escapes: `\n \t \\ \" \' \uXXXX`. f-strings start with `f`, `F`, or `ف`.

### 5.8 Lists, indexing & index assignment
```text
أ = [[١, ٢, ٣], [٤, ٥, ٦]]
اطبع(أ[٠][١])          # chained index read on a list  → ٢
أ[٠][٠] = ٩            # chained index assignment
م = نقل(أ)             # numpy array (matrix)
اطبع(م[٠, ١])          # N-D comma index — only on matrices/arrays
```
> **Note:** the comma form `م[ص, ع]` produces a tuple key and works **only on matrices/arrays** (e.g. results of `نقل`, `معكوس`). For plain lists use chained `أ[ص][ع]`.

### 5.9 Symbolic mathematics
```text
رمز س
د = س^٣ - ٦*س^٢ + ٩*س
اطبع("المشتقة:", اشتقق(د, س))        # 3·س² − 12·س + 9
اطبع("التكامل:", كامل(د, س))
اطبع("الجذور:", حلّ(د, س))
اطبع("النهاية:", نهاية((س^٢-١)/(س-١), س, ١))   # 2
```

## 7. Error Handling

Every error is a friendly, fully-Arabic message in the canonical form:

```
🌸 خطأ في السطر {رقم}، العمود {رقم}: {الرسالة}
   ↪ هل تقصد ‹الاقتراح›؟
   💡 {تلميح}
```

The error hierarchy distinguishes four categories, each with its own emoji and label:

| Category | Label | Emoji | Raised when |
|---|---|---|---|
| Lexical | `خطأ لفظي` | 🔤 | An invalid token / character. |
| Syntactic | `خطأ نحوي` | 📝 | The source violates the grammar. |
| Semantic | `خطأ دلالي` | 🔍 | Undefined name, wrong argument count, etc. |
| Runtime | `خطأ في التنفيذ` | ⚠️ | Division by zero, bad type, etc. |

When a name is misspelled, the analyzer offers a fuzzy *"did you mean…"* (`هل تقصد`) suggestion using closest-match matching, plus an optional hint (`💡`). Control-flow signals (`إرجع`/`اوقف`/`استمر`) are intentionally **not** part of the error hierarchy, so user-facing handlers never swallow them.

## 8. Demo — Running the Five Programs

The five programs in `examples/` together exercise the entire language. Run each with `python main.py examples/<file>`. *(Outputs below are shown with Arabic numerals, as printed by the language.)*

### ① `مرحبا.حع` — A gentle introduction
**Shows:** printing, variables, the six arithmetic operators, string length + `++` concatenation + f-strings, one user-defined function, an `إذا/وإلا` conditional, and a `لكل … من … إلى` loop.

```
مرحبًا بك في حاسوب عربي!
الجمع: ١٠
الطرح: ٤
الضرب: ٢١
القسمة: ٢.٣٣٣...
الباقي: ١
الأس: ٣٤٣
طول الاسم: ٤
تحية: مرحبًا يا جعفر
حاصل جمع ٧ و ٣ هو ١٠
مربع العدد ٦ هو: ٣٦
٧ أكبر من ٣
العد من ١ إلى ٥:
  العدد: ١ … ٥
```

### ② `إحصاء.حع` — Data analysis (statistics & plots)
**Shows:** all the statistics functions, sorting + slicing, `اختر`/`طبّق` lambdas, a multi-branch grading function, correlation, and two plots (histogram + scatter).

```
المتوسط: ٧٣.٨
الوسيط: ٧٦.٠
الانحراف المعياري: ١٤.٧٩...
أعلى درجة: ٩٥   أدنى درجة: ٤٨   المدى: ٤٧
أعلى ثلاث درجات: [٩٥, ٩٠, ٨٨]

### ③ `حساب_تفاضلي.حع` — Calculus toolkit
**Shows:** factoring, 1st/2nd derivatives, critical points via `حلّ`, classifying them with the second-derivative test (`عوّض`), indefinite & definite integrals, a 0/0 limit, a Taylor series, a numeric root, and a plot of the function with its derivative. Studied on `د(س) = س³ − ٦س² + ٩س`.

```
التحليل: س·(س − ٣)²
المشتقة الأولى: ٣·س² − ١٢·س + ٩
المشتقة الثانية: ٦·س − ١٢
النقاط الحرجة: [١, ٣]   →  س=١ نهاية عظمى، س=٣ نهاية صغرى
نهاية (س²−١)/(س−١) عند ١ = ٢
→ opens a plot of د and its derivative
```

### ④ `مصفوفات.حع` — Linear algebra
**Shows:** matrix multiply (`**`), transpose, determinant, inverse, eigenvalues, the **N-D comma index** `[ص, ع]`, **chained index assignment** building an identity matrix, `حلّ_خطي`, dot & cross products.

```
المحدد: -١.٠
الضرب المصفوفي A·B: [[٢, ١, ٥], [١, ٣, ٤], [١, ٠, ٢]]
القيم الذاتية: [٣.٩١, ١.٢٩, -٠.٢٠]
حل النظام الخطي: [١.٠, ٣.٠]
الضرب النقطي: ٣٢      الضرب المتجهي: [-٣, ٦, -٣]
```

### ⑤ `خوارزميات.حع` — Control flow & algorithms
**Shows:** recursion (factorial), `بينما` + augmented assignment (Fibonacci), an early-return prime test, `اوقف`/`استمر` in a loop, palindrome detection via `عكس`, `قسّم`/`دمج`, `طبّق`/`اختر` lambdas, chained comparisons, and `نوع` type checks.

```
عاملي ٥ = ١٢٠
أول ١٠ من فيبوناتشي: ٠ ١ ١ ٢ ٣ ٥ ٨ ١٣ ٢١ ٣٤
