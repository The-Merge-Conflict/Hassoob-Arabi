## ١. نظرة عامة

**حاسوب عربي** لغة برمجة كاملة تكون فيها **الكلمات المفتاحية والمعرّفات والأرقام ورسائل الأخطاء كلها بالعربية**، وملفاتها المصدرية بالامتداد `.حع`. وهي مستوحاة من Wolfram Mathematica: فإلى جانب البرمجة الإجرائية المعتادة، تتعامل مع **الرياضيات الرمزية** كمواطن من الدرجة الأولى — فيمكنك تعريف الرموز، والاشتقاق، والتكامل، وإيجاد النهايات، ونشر متسلسلات تايلور، وحل المعادلات، والعمل على المصفوفات، وحساب الإحصاءات، ورسم البيانات، كل ذلك بأوامر عربية.

أبرز الخصائص:

- **بنية عربية** — كلمات التحكم (`إذا`، `بينما`، `لكل`، `دالة`، …) والدوال المدمجة (`اطبع`، `اشتقق`، `متوسط`، …) والعوامل تُقرأ طبيعيًا بالعربية.
- **أرقام عربية (هندية)** — يقبل المصدر `٠١٢٣` و`0123` معًا، و**كل المخرجات تُطبع بالأرقام العربية** (٠–٩).
- **محرّك رمزي + عددي** — جبر/تفاضل رمزي عبر SymPy، وحساب عددي/جبر خطي سريع عبر NumPy، ورسوم عبر Matplotlib.
- **أخطاء لطيفة** — كل خطأ رسالة عربية لطيفة بالصيغة `خطأ في السطر {س}، العمود {ع}: …`، وغالبًا مع اقتراح *«هل تقصد…»*.
- **بيئة تطوير يمينية (RTL)** — محرّر يميني مع تلوين للبنية، تشغيل فوري، وصدفة تفاعلية.

## ٢. البنية ومسار الترجمة

حاسوب عربي **مفسّر يجوب الشجرة (tree-walking)** مبني على واجهة أمامية من ANTLR4. يمرّ الملف المصدري بالمراحل التالية:

```
  المصدر.حع
      │
      ▼
┌──────────────┐   مُحلّل لفظي + نحوي يولّدهما ANTLR4 من HassoobArabi.g4
│ الواجهة الأمامية │   → شجرة تحليل (parse tree)
└──────────────┘
      │
      ▼
┌──────────────┐   ast_builder.py يجوب شجرة التحليل
│  باني الشجرة   │   → شجرة بناء مجرّدة AST (ast_nodes.py)
└──────────────┘
      │
      ▼
┌──────────────┐   semantic.py: فحص المتغيّرات غير المعرّفة، عدد الوسائط،
│ التحليل الدلالي │   موضع إرجع/اوقف/استمر، واقتراحات «هل تقصد»
└──────────────┘
      │
      ▼
┌──────────────┐   optimizer.py: طيّ الثوابت، التبسيط الجبري،
│   المُحسّن     │   حذف الفروع الميتة
└──────────────┘
      │
      ▼
┌──────────────┐   interpreter.py يجوب الشجرة؛ environment.py يحمل سلسلة
│   المُفسّر     │   النطاقات؛ builtins.py يوفّر المكتبة القياسية
└──────────────┘
      │
      ▼
  مخرجات الطرفية (أرقام عربية) + نوافذ رسم Matplotlib
```

**مسؤوليات المراحل**

| المرحلة | الوحدة(ات) | المسؤولية |
|---|---|---|
| التحليل اللفظي والنحوي | `generated/` (من `HassoobArabi.g4`) | تقطيع المصدر العربي وبناء شجرة التحليل وفق القواعد. |
| بناء الشجرة | `src/ast_builder.py`، `src/ast_nodes.py` | تحويل شجرة التحليل إلى عقد AST. |
| التحليل الدلالي | `src/semantic.py` | فحوص ساكنة: الأسماء غير المعرّفة، عدد الوسائط، مواضع `إرجع`/`اوقف`/`استمر`. |
| التحسين | `src/optimizer.py` | طيّ الثوابت، التبسيط، حذف الفروع غير القابلة للوصول. |
| التفسير | `src/interpreter.py`، `src/environment.py` | تنفيذ الشجرة؛ إدارة سلسلة النطاقات بأسلوب Mathematica. |
| المكتبة القياسية | `src/builtins.py`، `src/runtime_ops.py`، `src/lang_utils.py` | الدوال المدمجة ودلالات العوامل والمساعدات. |
| الأخطاء | `src/errors.py` | شجرة استثناءات عربية لطيفة + إشارات التحكم. |
| الأدوات | `src/repl.py`، `ide/` | الصدفة التفاعلية وبيئة التطوير الرسومية اليمينية. |

## ٤. التثبيت والتشغيل

### المتطلبات
- Python 3.10+
- `antlr4-python3-runtime`، `sympy`، `numpy`، `matplotlib`، `scipy`، `prompt_toolkit`، `rich`، `pytest`
- `PySide6` *(اختياري)* — يفعّل محرّر Qt اليميني الصحيح؛ وبدونه تعود البيئة إلى Tkinter.

### الإعداد
```bash
pip install -r requirements.txt

# توليد المحلّل من القواعد (يتطلب Java + أداة antlr4):
antlr4 -Dlanguage=Python3 -visitor -o generated HassoobArabi.g4
```

### التشغيل
```bash
python main.py                     # الصدفة التفاعلية (REPL)
python main.py examples/مرحبا.حع    # تشغيل ملف مصدري
python main.py -c "اطبع(٣+٤)"       # تنفيذ تعبير واحد
python main.py --ide               # فتح بيئة التطوير الرسومية
python -m ide                      # (مكافئ) فتح البيئة الرسومية
```

### الاختبارات
```bash
pytest tests/
# كل ملف اختبار يعمل مستقلًّا ويبني الشجرة مباشرةً،
# لذا تنجح الاختبارات حتى قبل توليد محلّل ANTLR.
```

## ٥. مرجع اللغة

### ٥.١ الأرقام والتعليقات والجُمل
- **الأرقام:** تُقبل العربية (`٠١٢٣٤٥٦٧٨٩`) والغربية (`0-9`) معًا. العدد العشري يتطلب نقطة ASCII: `٢.٥`.
- **الجُمل** تنتهي بنهاية السطر؛ ويُسمح بفاصلة منقوطة اختيارية `;` أو الفاصلة المنقوطة العربية `؛`.
- **التعليقات:**
  - `# ...` — تعليق سطري
  - `ملاحظة ...` — تعليق سطري عربي
  - `/* ... */` — تعليق كتلي

### ٥.٢ المتغيرات والإسناد
```text
أ = ٧                 # إسناد
أ += ٣                # إسناد مركّب: += -= *= /= %= ^= ++=
النص ++= "!"          # ++= يُلحق بالنص
```
يستخدم المفسّر **سلسلة نطاقات بأسلوب Mathematica**: تُنشئ الدوال نطاقًا جديدًا وتحلّ الأسماء الحرة عبر النطاقات المحيطة.

### ٥.٣ أنواع البيانات
| النوع | تُرجِع `نوع` | مثال |
|---|---|---|
| عدد | `عدد` | `٣`، `٢.٥`، `-٧` |
| منطقي | `منطقي` | `صحيح`، `خطأ` |
| نص | `نص` | `"مرحبا"`، `'نص'` |
| فارغ | `فارغ` | `فارغ` |
| قائمة | `قائمة` | `[١, ٢, ٣]` |
| مصفوفة | `مصفوفة` | `[[١,٢],[٣,٤]]` (عبر العمليات العددية) |
| رمزي | `رمزي` | ناتج `رمز س` |
| دالة | `دالة` | `دالة` أو تعبير سهمي |

### ٥.٤ العوامل
| الفئة | العوامل |
|---|---|
| حسابية | `+`  `-`  `*`  `/`  `%` (الباقي)  `^` (الأس)  `÷` (القسمة الصحيحة) |
| مصفوفية | `**` (ضرب المصفوفات) |
| نصية | `++` (الدمج — ينسّق الطرفين) |
| مقارنة | `==`  `!=`/`≠`  `<`  `<=`/`≤`  `>`  `>=`/`≥` (قابلة للتسلسل: `٦٠ <= د < ٩٠`) |
| منطقية | `و`/`&&`  `أو`/`||`  `ليس`/`!` |
| إسناد | `=`  `+=`  `-=`  `*=`  `/=`  `%=`  `^=`  `++=` |
| السهم | `=>` |

**الثوابت الرمزية:** `باي` / `π`، `هـ` (عدد أويلر)، `لانهاية`.

### ٥.٥ التحكم في التدفّق
```text
# شرط
إذا (أ > ب) {
    اطبع("أكبر")
} وإلا إذا (أ == ب) {
    اطبع("متساوٍ")
} وإلا {
    اطبع("أصغر")
}

# حلقة بينما
بينما (س < ١٠) { س += ١ }

# لكل ... في تسلسل
لكل عنصر في [١, ٢, ٣] { اطبع(عنصر) }

# لكل ... من ... إلى (شامل للطرفين؛ بخطوة اختيارية)
لكل ع من ١ إلى ٥ { اطبع(ع) }
لكل ع من ١٠ إلى ١ بخطوة -٢ { اطبع(ع) }
```
`اوقف` = كسر الحلقة، `استمر` = متابعة.

### ٥.٦ الدوال والتعابير السهمية
```text
دالة مربع(س) {
    إرجع س * س
}

دالة عاملي(ن) {
    إذا (ن <= ١) { إرجع ١ }
    إرجع ن * عاملي(ن - ١)     # استدعاء ذاتي
}

# تعابير سهمية: وسيط واحد بلا أقواس، أو (أ, ب) => ...
مضاعف = س => س * ٢
جمع    = (أ, ب) => أ + ب
```

### ٥.٧ النصوص وقوالب النص
```text
الاسم = "جعفر"
اطبع("مرحبًا يا " ++ الاسم)            # الدمج بالعامل ++
اطبع(f"الطول هو {طول(الاسم)} حروف")   # قالب نص (f-string)
```
الهروب: `\n \t \\ \" \' \uXXXX`. تبدأ قوالب النص بـ `f` أو `F` أو `ف`.

### ٥.٨ القوائم والفهرسة وإسناد الفهرس
```text
أ = [[١, ٢, ٣], [٤, ٥, ٦]]
اطبع(أ[٠][١])          # قراءة فهرس متسلسلة على قائمة  → ٢
أ[٠][٠] = ٩            # إسناد فهرس متسلسل
م = نقل(أ)             # مصفوفة numpy
اطبع(م[٠, ١])          # فهرس بفاصلة (N-D) — على المصفوفات فقط
```
> **ملاحظة:** صيغة الفاصلة `م[ص, ع]` تُنتج مفتاحًا من نوع tuple وتعمل **على المصفوفات/المصفوفات العددية فقط** (مثل ناتج `نقل` أو `معكوس`). أمّا القوائم العادية فاستعمل الفهرسة المتسلسلة `أ[ص][ع]`.

### ٥.٩ الرياضيات الرمزية
```text
رمز س
د = س^٣ - ٦*س^٢ + ٩*س
اطبع("المشتقة:", اشتقق(د, س))        # ٣·س² − ١٢·س + ٩
اطبع("التكامل:", كامل(د, س))
اطبع("الجذور:", حلّ(د, س))
اطبع("النهاية:", نهاية((س^٢-١)/(س-١), س, ١))   # ٢
```

## ٧. معالجة الأخطاء

كل خطأ رسالة عربية لطيفة بالصيغة المعيارية:

```
🌸 خطأ في السطر {رقم}، العمود {رقم}: {الرسالة}
   ↪ هل تقصد ‹الاقتراح›؟
   💡 {تلميح}
```

تميّز شجرة الأخطاء أربع فئات، لكلٍّ رمزها التعبيري وعنوانها:

| الفئة | العنوان | الرمز | تُطلَق عند |
|---|---|---|---|
| لفظي | `خطأ لفظي` | 🔤 | رمز/محرف غير صالح. |
| نحوي | `خطأ نحوي` | 📝 | مخالفة القواعد. |
| دلالي | `خطأ دلالي` | 🔍 | اسم غير معرّف، عدد وسائط خاطئ، إلخ. |
| تنفيذي | `خطأ في التنفيذ` | ⚠️ | قسمة على صفر، نوع خاطئ، إلخ. |

عند الخطأ الإملائي في اسم، يقترح المحلّل أقرب تطابق *«هل تقصد…»*، مع تلميح اختياري (`💡`). أمّا إشارات التحكم (`إرجع`/`اوقف`/`استمر`) فليست — عمدًا — جزءًا من شجرة الأخطاء، حتى لا تبتلعها معالِجات الأخطاء.

## ٨. العرض — تشغيل البرامج الخمسة

تغطّي البرامج الخمسة في `examples/` اللغة بأكملها. شغّل كلًّا منها بـ `python main.py examples/<الملف>`. *(المخرجات أدناه بأرقام عربية كما تطبعها اللغة.)*

### ① `مرحبا.حع` — مقدمة بسيطة
**يُظهر:** الطباعة، المتغيرات، العمليات الحسابية الستّ، طول النص + الدمج `++` + قوالب النص، دالة معرّفة، شرط `إذا/وإلا`، وحلقة `لكل … من … إلى`.

```
مرحبًا بك في حاسوب عربي!
الجمع: ١٠
الطرح: ٤
الضرب: ٢١
القسمة: ٢.٣٣٣...
الباقي: ١
الأس: ٣٤٣
طول الاسم: ٤
تحية: مرحبًا يا جعفر
حاصل جمع ٧ و ٣ هو ١٠
مربع العدد ٦ هو: ٣٦
٧ أكبر من ٣
العد من ١ إلى ٥: ١ … ٥
```

### ② `إحصاء.حع` — تحليل بيانات (إحصاء ورسوم)
**يُظهر:** كل دوال الإحصاء، الترتيب + التقطيع، تعابير `اختر`/`طبّق` السهمية، دالة تقدير متعددة الفروع، الارتباط، ورسمين (مدرّج تكراري + سحابة نقاط).

```
المتوسط: ٧٣.٨
الوسيط: ٧٦.٠
الانحراف المعياري: ١٤.٧٩...
أعلى درجة: ٩٥   أدنى درجة: ٤٨   المدى: ٤٧
أعلى ثلاث درجات: [٩٥, ٩٠, ٨٨]
الدرجات الناجحة (≥ ٦٠): [٧٨, ٩٠, ٦٢, ٨٨, ٧٤, ٩٥, ٨١, ٦٧]   (عدد الناجحين: ٨)
بعد منح ٥ درجات: [٦٠, ٨٣, ٩٥, ٦٧, ٩٣, ٧٩, ١٠٠, ٥٣, ٨٦, ٧٢]
معامل الارتباط بين الاختبارين: ٠.٩٧٣...
→ تُفتح نافذة مدرّج تكراري ونافذة سحابة نقاط
```

### ③ `حساب_تفاضلي.حع` — صندوق أدوات التفاضل والتكامل
**يُظهر:** التحليل، المشتقة الأولى والثانية، النقاط الحرجة عبر `حلّ`، تصنيفها باختبار المشتقة الثانية (`عوّض`)، التكامل غير المحدّد والمحدّد، نهاية ٠/٠، متسلسلة تايلور، جذر عددي، ورسم الدالة مع مشتقتها. مدروس على `د(س) = س³ − ٦س² + ٩س`.

```
التحليل: س·(س − ٣)²
المشتقة الأولى: ٣·س² − ١٢·س + ٩
المشتقة الثانية: ٦·س − ١٢
النقاط الحرجة: [١, ٣]   →  س=١ نهاية عظمى، س=٣ نهاية صغرى
نهاية (س²−١)/(س−١) عند ١ = ٢
→ تُفتح نافذة رسم للدالة ومشتقتها
```

### ④ `مصفوفات.حع` — الجبر الخطي
**يُظهر:** ضرب المصفوفات (`**`)، المنقول، المحدّد، المعكوس، القيم الذاتية، **الفهرسة بفاصلة** `[ص, ع]`، **إسناد الفهرس المتسلسل** لبناء مصفوفة الوحدة، `حلّ_خطي`، والضربين النقطي والمتجهي.

```
المحدد: -١.٠
الضرب المصفوفي A·B: [[٢, ١, ٥], [١, ٣, ٤], [١, ٠, ٢]]
القيم الذاتية: [٣.٩١, ١.٢٩, -٠.٢٠]
حل النظام الخطي: [١.٠, ٣.٠]
الضرب النقطي: ٣٢      الضرب المتجهي: [-٣, ٦, -٣]
```

### ⑤ `خوارزميات.حع` — التحكم في التدفّق والخوارزميات
**يُظهر:** الاستدعاء الذاتي (العاملي)، `بينما` + إسناد مركّب (فيبوناتشي)، اختبار أوّلية بإرجاع مبكر، `اوقف`/`استمر` في حلقة، كشف التناظر عبر `عكس`، `قسّم`/`دمج`، تعابير `طبّق`/`اختر`، مقارنات متسلسلة، وفحوص `نوع`.

```
عاملي ٥ = ١٢٠
أول ١٠ من فيبوناتشي: ٠ ١ ١ ٢ ٣ ٥ ٨ ١٣ ٢١ ٣٤
الأعداد الأولية حتى ٢٠: ٢ ٣ ٥ ٧ ١١ ١٣ ١٧ ١٩
"ليل" متناظرة؟ صحيح
```
